Lebensplaner einrichten

Verbinde die App mit deinem privaten GitHub-Repository. Alle Daten werden dort als JSON-Dateien gespeichert – es gibt kein eigenes Backend.

Wird nur lokal in diesem Browser gespeichert (localStorage), niemals im Code oder Repo.
Wie erstelle ich einen passenden Token?
  1. Lege ein privates GitHub-Repo an, das nur für deine Lebensplaner-Daten dient.
  2. Gehe zu github.com/settings/personal-access-tokens/new (Fine-grained Token).
  3. Beschränke den Zugriff auf genau dieses eine Repository.
  4. Setze unter „Repository permissions“ → Contents auf Read and write.
  5. Erstelle den Token und füge ihn oben ein.
